# Monochrome Devourer

一款仅在玩家主动展开时运行的 Windows 黑白像素桌宠游戏。

玩家从桌面角落里一颗指甲盖大小的黑白星球开始，只用方向键控制一只没有技能的小怪物。它通过吞噬、躲避、器官拆解和不可逆进化逐渐成长；击败世界 Boss 后吞噬整颗星球，进入更大的生命尺度。

> 当前状态：Pre-production / MVP 目标已冻结  
> 目标平台：Windows  
> 技术栈：Tauri 2 + Rust + TypeScript + PixiJS 8  
> AI：DeepSeek（受约束的低频导演，不参与实时模拟）

## Product Goal

构建一个可在桌面角落和全屏游戏之间无缝切换的像素桌宠：

- 暂停时，世界折叠成桌面角落的“黑白星核”；
- 点击星核或按全局快捷键后，世界展开到当前尺度；
- 激活后实时运行，玩家仅使用方向键；
- `Esc` 或点击游戏外部后立即暂停并折叠；
- 游戏暂停时不捕获方向键，也没有离线成长；
- 宠物从微小可爱逐渐进化成诡异、宏大的宇宙生命；
- 标志性器官贯穿进化和重生，维持角色身份。

## Visual Direction

整体采用严格的黑白像素风格：

- 以纯黑、纯白为主，灰度通过像素抖动表达；
- 使用 nearest-neighbor 缩放，禁止模糊插值；
- 像素必须对齐整数坐标；
- 小尺度轮廓可爱、清晰、容易辨认；
- 随着进化，轮廓逐渐不对称、器官化和宇宙恐怖化；
- 身体由程序化像素轮廓和 3–5 个可识别器官组成；
- 不依赖运行时 AI 生图。

## Core Loop

1. 从桌面角落展开星球。
2. 用方向键移动。
3. 吞噬比自己小的怪物，积累质量。
4. 躲避比自己大的捕食者。
5. 应对怪潮或精英入侵。
6. 达到公开质量阈值后挑战世界 Boss。
7. 用头部咬掉 Boss 的外显器官，使其能力和体型同步衰减。
8. 吞噬核心和星球。
9. 从三个不可逆进化候选中选择一个。
10. 进入更大的生命尺度。

## Controls

- `↑ / ↓ / ← / →`：移动
- 头部接触：自动咬击
- 侧面或尾部被撞：损失质量
- `Esc`：暂停并折叠世界
- 点击星核或全局快捷键：展开世界

游戏进入激活态后持续实时运行；松开方向键不会暂停。

## Ecology

常态采用捕食链：

- 小怪逃离玩家；
- 大怪追逐玩家；
- 同级怪争夺食物；
- 特殊条件触发怪潮或精英入侵。

首个 MVP 只包含：

- 1 颗星球；
- 3 类普通怪；
- 1 个精英事件；
- 1 个可拆解器官的世界 Boss；
- 1 次吞噬星球后的大进化；
- 累计 20–30 分钟激活游戏时间。

## Growth and Evolution

成长分为三层：

### Mass Growth

普通吞噬只增加质量。体型只轻微增加惯性，基础操控始终保持灵敏。

### Minor Mutation

文件投喂或稀有事件可以产生小变异：

- 立即生成纹理、触须、裂纹等像素体征；
- 提供轻量特性；
- 相关基因永久写入基因库；
- 未来大进化时可能升级为正式器官。

### Major Evolution

吞噬世界 Boss 和星球后触发：

- DeepSeek 或本地生成器产生三个合法候选；
- 展示外形轮廓和主要能力；
- 隐藏副作用、未来融合条件和稀有变异；
- 玩家三选一；
- 选择完全不可逆。

全部基因永久保留，但身体只表达 3–5 个正式器官。

## Failure and Rebirth

- 普通受伤损失质量；
- 质量归零后进入“蛹化重生”；
- 玩家指定一个当前器官作为“遗器”；
- 其余身体死亡；
- 完整基因库继续保留；
- DeepSeek 或本地生成器根据遗器和基因库生成三个重构体；
- 玩家三选一后继续不可逆成长。

## File Feeding and Privacy

文件投喂必须满足特殊进化条件才能解锁。

安全规则：

- 原文件永不删除、移动或修改；
- 只处理玩家明确拖入的单个文件；
- 原始文件永不上传；
- 本地提取匿名特征；
- 在发送前展示完整的“将发送内容”；
- 只有玩家确认后才请求 DeepSeek；
- 使用内容指纹去重；
- 同一文件只能触发一次主要变异；
- 重复投喂只提供普通营养。

MVP 文件支持：

- 图片：尺寸、宽高比、明暗、边缘密度，不发送像素；
- 文本：长度、语言、标点密度和本地脱敏关键词；
- 其他文件：只使用扩展名、大小等元数据。

## DeepSeek Boundary

DeepSeek 只允许输出四种结构化配方：

- `EventRecipe`
- `MutationRecipe`
- `EvolutionRecipe`
- `RebirthRecipe`

DeepSeek 不得：

- 控制实时怪物行为；
- 决定碰撞结果；
- 直接修改存档；
- 输出或执行代码；
- 读取任意文件；
- 阻塞游戏流程。

所有模型输出必须经过：

1. JSON 解析；
2. Schema 校验；
3. 枚举白名单校验；
4. 器官数量校验；
5. 数值范围校验；
6. 总强度预算校验。

任何断网、超时、空响应或非法配方都立即使用带种子的本地生成器。后台重试不得推翻玩家已经看见或选择的结果。

## Technical Architecture

### Rust / Tauri

负责：

- `star-core` 星核窗口；
- `world-overlay` 全屏透明世界窗口；
- 全局快捷键、焦点和点击穿透；
- SQLite 存档；
- API Key 安全存储；
- 文件读取、匿名特征和内容指纹；
- DeepSeek HTTP 请求；
- 配方校验与本地降级。

### TypeScript / PixiJS

负责：

- 固定时间步实时模拟；
- 键盘输入；
- 捕食链 AI；
- 头部、侧面和尾部碰撞；
- Boss 器官碰撞体；
- 程序化像素身体；
- 粒子、吞噬和世界展开动画。

逐帧模拟不得通过 Tauri IPC 往返。

## Codex Mission

Codex 应按照以下顺序完成项目，不得提前扩张范围。

### Phase 0 — Windows Windowing Spike

首先只验证：

- 创建透明、无边框、置顶的星核窗口；
- 创建透明全屏世界窗口；
- 点击星核或按快捷键展开；
- `Esc` 和点击外部折叠；
- 折叠后完全停止模拟；
- 折叠后不捕获方向键；
- 连续展开/折叠 100 次无焦点丢失、黑屏或僵尸窗口；
- PixiJS 在 1080p 下稳定渲染一个黑白像素生物。

Phase 0 未通过前，不得接入 DeepSeek，不得实现进化系统。

### Phase 1 — Local Graybox

- 方向键移动；
- 朝向和头部咬击；
- 侧后方受伤；
- 三种普通怪；
- 质量增长和损失；
- 固定随机种子；
- 暂停、存档和恢复；
- 本地精英事件。

### Phase 2 — Boss and Body

- 程序化像素身体；
- 3–5 个器官槽；
- 器官改变速度、转向或冲撞；
- Boss 器官拆解；
- 吞噬核心和星球；
- 本地三选一大进化。

### Phase 3 — DeepSeek Director

- Rust 侧 API Client；
- 四类 Recipe；
- JSON + 规则预算双重校验；
- 超时和本地降级；
- 不可变配方日志。

### Phase 4 — File Feeding

- 单文件拖入；
- 本地匿名特征；
- 发送预览和确认；
- 内容指纹去重；
- 小变异。

### Phase 5 — Playtest

- 调整 20–30 分钟节奏；
- 验证方向键 Boss 战；
- 验证不可逆选择是否形成依恋；
- 验证全屏世界是否干扰办公。

## Acceptance Criteria

### Technical

- 暂停时 simulation tick 完全停止；
- 暂停时方向键永不被捕获；
- 1080p、30 个实体时稳定达到 60 FPS；
- DeepSeek 完全不可用时仍能通关；
- 强制退出后最多丢失 5 秒状态；
- 文件投喂前后原文件哈希不变；
- 网络请求不包含原文件字节或未展示内容。

### Gameplay

- 新玩家在 30 秒内理解“大吃小、头咬、侧后受伤”；
- 5 名测试者中至少 4 名能只用方向键击败 Boss；
- 第一颗星球耗时 20–30 分钟；
- 至少 3 名测试者完成大进化后愿意再次打开游戏。

## Explicit Non-goals

MVP 不做：

- 自动巡游和离线成长；
- 聊天、语音、人格和长期记忆；
- 多模型 Provider UI；
- 插件系统；
- macOS 和 Linux；
- 多颗星球或真正无限生成；
- AI 实时控制敌人；
- AI 生成贴图；
- 全文上传文件；
- ECS、外部物理引擎、微服务或云账号。

## Development Principle

优先级固定为：

**窗口共存体验 → 吞噬手感 → Boss 拆解 → 程序化像素身体 → DeepSeek 随机性**

如果前四项不好玩，DeepSeek 只会生成更多不好玩的内容。
